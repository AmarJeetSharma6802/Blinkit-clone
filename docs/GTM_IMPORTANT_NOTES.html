GTM Tracking Important Notes

Project: Blinkit Clone | Container: GTM-K9DRNHRR

Short summary: Website me Google Tag Manager install hai. Code ecommerce actions ko window.dataLayer me push karta hai. GTM me marketer Google Ads / GA4 tags ko in events par fire kara sakta hai.

1. GTM Script Kahan Use Hua Hai

GTM script Layout.jsx me nahi hai. Script root file index.html me add hai.

Head script

<script>
  (function (w, d, s, l, i) {
    w[l] = w[l] || [];
    w[l].push({
      "gtm.start": new Date().getTime(),
      event: "gtm.js"
    });
    var f = d.getElementsByTagName(s)[0],
      j = d.createElement(s),
      dl = l != "dataLayer" ? "&l=" + l : "";
    j.async = true;
    j.src = "https://www.googletagmanager.com/gtm.js?id=" + i + dl;
    f.parentNode.insertBefore(j, f);
  })(window, document, "script", "dataLayer", "GTM-K9DRNHRR");
</script>

Body noscript

<noscript>
  <iframe
    src="https://www.googletagmanager.com/ns.html?id=GTM-K9DRNHRR"
    height="0"
    width="0"
    style="display:none;visibility:hidden"
  ></iframe>
</noscript>

Meaning: Website load hote hi GTM container browser me load ho jata hai.

2. Layout File Ka Role

src/Layout.jsx only app structure render karta hai:

<Header />
<Outlet />
<Footer />

Outlet ke andar current route page load hota hai, jaise Home, Checkout, Success.

3. dataLayer Helper Function

File: src/lib/gtm.ts

export const pushToDataLayer = (data: object) => {
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push(data);
};

Ye function event object ko GTM ke dataLayer me bhejta hai.

9. Ecommerce Object Ka Meaning

Field Meaning
event GTM trigger ke liye event name, e.g. purchase
currency Currency code, yahan INR
value Total amount ya product amount
transaction_id Purchase order id. Fake payment me Date.now se unique id ban rahi hai.
items Cart/products ki array
item_id Product id
item_name Product name
price Product price
quantity Product quantity

10. Item Name Undefined Fix

Pehle kuch products ka naam FirstP me tha aur kuch selected product pages ka naam name me tha. Isliye kabhi item_name undefined aa raha tha.

Reducer me normalize kiya gaya:

const itemName = newItem.name || newItem.FirstP;

name: itemName,
FirstP: itemName

Events me fallback use hua:

item.name || item.FirstP || "Unknown Product"
Agar browser localStorage me old cart item pehle se undefined ke saath saved hai, to cart clear karke item dobara add karna hoga.

11. Live Tracking Simple Explanation

Tag Assistant Connect sirf debug ke liye hota hai. Real users ko connect karne ki zarurat nahi hoti.

Live tracking ke liye GTM me tags publish hone chahiye.

  1. Website open hoti hai.
  2. index.html se GTM script load hoti hai.
  3. User action karta hai, e.g. ADD, cart open, pay now.
  4. React code pushToDataLayer call karta hai.
  5. GTM published trigger event pakadta hai.
  6. Google Ads / GA4 tag fire hota hai.

12. Undefined Fields In GTM Preview

Preview me ye fields dikh sakti hain:

allowlist: undefined
blocklist: undefined
whitelist: undefined
blacklist: undefined
tagTypeBlacklist: undefined

Ye hamare ecommerce data ka issue nahi hai. Ye GTM internal debug fields hain. Hum code se ye fields push nahi kar rahe.

Important check ye hai ki ecommerce.items ke andar item_name, price, quantity sahi aa rahe hain.

13. UTM Add Kiya Hai Ya Nahi?

Nahi. Is website me abhi UTM reader/pusher code add nahi kiya gaya.

Humne GTM + ecommerce dataLayer tracking add ki hai.

UTM URL parameters hote hain:

?utm_source=google&utm_medium=cpc&utm_campaign=sale

Google Ads ke liye generally gclid auto-tagging + Conversion Linker use hota hai. UTM separate reporting need ho to later add kiya ja sakta hai.

14. GTM Me Marketer Ko Kya Configure Karna Hai

  1. GTM container GTM-K9DRNHRR open karo.
  2. Conversion Linker tag add karo, trigger: All Pages.
  3. Google Ads Conversion tag add karo.
  4. Purchase conversion ke liye trigger: Custom Event purchase.
  5. Value variable: ecommerce.value.
  6. Currency variable: ecommerce.currency.
  7. Transaction variable: ecommerce.transaction_id.
  8. Preview mode me test karo.
  9. Container publish karo.

15. GTM vs GA4 vs UTM Difference

Term Full Form / Meaning Kaam Kya Hai Example
GTM Google Tag Manager Tags manage/run karta hai bina code baar-baar deploy kiye. GTM-K9DRNHRR
GA4 Google Analytics 4 Website/app analytics reports banata hai, events aur users track karta hai. purchase, add_to_cart reports
UTM Urchin Tracking Module URL campaign source/medium/campaign identify karta hai. utm_source=google

16. One Line For Performance Marketer

Website GTM-ready hai aur ecommerce events dataLayer me push ho rahe hain. Marketer ko GTM me Google Ads/GA4 tags ko custom events par configure aur publish karna hai.
